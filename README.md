# Gym — журнал тренувань

Односторінковий трекер для 12-тижневої програми рекомпозиції (дні A/B/C).
Працює без сервера, дані зберігаються в `localStorage` браузера (ключі `gym-tracker:*`).

## Можливості
- Тренування дня з автопідказкою дня за чергою (A → B → C)
- Фази за тижнями (повернення / основна / розвантаження / інтенсифікація) з кількістю підходів і RIR
- «Минулого разу» + підказка прогресії (+1,25 кг, коли всі підходи на верхній межі)
- Таймер відпочинку, автозбереження чернетки
- Історія з редагуванням, графіки прогресу (розрахунковий 1ПМ), вага й талія з тижневими середніми
- Експорт / імпорт JSON, запит постійного сховища

## Публікація на GitHub Pages
1. Створи репозиторій (напр. `gym-tracker`) і завантаж туди `index.html`.
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 хв сайт буде на `https://<username>.github.io/gym-tracker/`.
4. На телефоні: додай сайт на головний екран і відкривай звідти.
